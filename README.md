# 盒装刷铁机（Boxed Iron Farm）Fabric 模组

适配 **Minecraft 1.21.5** 的 Fabric 模组，在游戏里添加“盒装刷铁机”系列方块。

## 内容

| 物品/方块 | 说明 |
|---|---|
| 空的盒装刷铁机 | 对着**僵尸**或**村民**右键使用，把它们装进盒子里 |
| 有僵尸的盒装刷铁机 | 对着**村民**右键使用，把村民装进去 |
| 有村民的盒装刷铁机 | 对着**僵尸**右键使用，把僵尸装进去 |
| 盒装刷铁机（完整） | 同时装有僵尸和村民，**放置后每 30 秒产出 4 个铁锭**，右键打开漏斗式 GUI |

- 完整盒装刷铁机是一个 **5 格容器**，GUI 复用漏斗界面（5 格 + 玩家背包），标题为“盒装刷铁机”。
- 产出的铁锭会放进容器；容器满了多余的铁锭掉落在方块旁。
- 破坏方块会掉落内部物品。

## 外观

顶部与四面为玻璃，底部一层石头，石头内有坑、坑内是岩浆，岩浆左边是僵尸、右边是村民（不同变体对应不同的“装盒”状态）。

## 合成配方（空的盒装刷铁机）

```
玻 玻 玻
原 浆 原
原 漏 原
```

- 玻璃 ×5、原石 ×3、漏斗 ×1、岩浆桶 ×1
- 合成后**返还一个空桶**（岩浆桶不会白白消耗）

## 使用方法

1. 准备：`glass ×5 + cobblestone ×3 + hopper ×1 + lava_bucket ×1` → 空的盒装刷铁机（返还空桶）
2. 捕捉：拿着空的盒装刷铁机右键僵尸/村民 → 得到对应变体
3. 凑齐：有僵尸的刷铁机右键村民（或有村民的右键僵尸）→ 完整的盒装刷铁机
4. 产铁：放置完整的盒装刷铁机，每 30 秒自动产出 4 个铁锭，右键查看/取出

## 构建

需要 JDK 21：

```bash
./gradlew build
# 产物在 build/libs/boxed-iron-farm-1.0.0.jar
```

## 安装

1. 安装 [Fabric Loader](https://fabricmc.net/use/)（0.16.10+）
2. 安装 [Fabric API](https://modrinth.com/mod/fabric-api)（1.21.5 版本）
3. 把 `boxed-iron-farm-1.0.0.jar` 放进 `mods/` 文件夹
